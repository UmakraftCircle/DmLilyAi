# Umamusume Glossary

Source: uma.guide Glossary (190 terms). Definitions are condensed and paraphrased. Skill effect values (Target Speed, Acceleration and so on) are as shown on the source page.

**Table columns:** Term, Also Known As (nicknames and abbreviations), Definition.

| Term | Also Known As | Definition |
| --- | --- | --- |
| 11/11 | - | The accelerated Global update of November 11, 2025, which brought 1st Anniversary balance changes and quality-of-life improvements. |
| A Kiss for Courage | KFC | Skill. Target Speed +0.35. |
| Accel Zone | Final Leg | The first half of the late-race, where the Uma accelerates toward Top Speed. Shown as phase=2 in Skill Conditions. |
| Acceleration | - | The rate at which an Uma's Velocity increases. |
| Acceleration Skills | - | Skills that raise Current Speed over time. Shown in-game by a sweating Uma in the Skill icon. |
| Ace | - | An Uma built to win PvP Races. |
| Activate | Proc | Term for something occurring, for example a Skill procing means it activates. |
| Admire Vega | Ayabe, AV | The Umamusume Admire Vega. |
| Agemasen | I didnt hit :( | A Support Card Chain Event failing to complete, or failing a failable final Chain Event. Named after a scene in Season 2 where Special Week denies Mejiro McQueen in Teio's dream sequence. It became notorious in CM1 and CM2, when the Special Week Speed SSR was used to get Gourmand but could sometimes give the white version, Hydrate. |
| Angling and Scheming | Rod, Anski | Skill. Acceleration +0.4. |
| Anime Collab | Anime | Anime collaboration versions of characters, which have many special shorthand names, for example Red Teio, Cinderella Gray (Cingray) Oguri and Anime Mcqueen. |
| Aptitude | - | An Uma's compatibility with a Style, Distance or Ground Type. |
| Autumn | [X Char] Alt | Autumn alternate outfits, for example Autumn Neo Universe and Autumn K.S. Miracle. |
| Backline | - | Usually End Closers and Late Surgers. Can include Pace Chasers depending on context. |
| Backstretch | - | The straight on the side of the track opposite the crowd. |
| Ballroom | Droite | Alternate outfit naming, for example Soirée de Chaton Seiun Sky and Ballroom Fuji Kiseki. |
| Banner | Gacha | The game's gacha system, split into Uma and Support Card Banners. Banners often have better rates for specific Umas or Support Cards. |
| Base Target Speed | - | The lowest Target Speed an Uma has at any point in a Race. It changes with the phase of the Race. |
| Bermuda Triangle | Bermuda | A team of three Umas with independent acceleration conditions, who enter the final straight and duel each other. Often run as 3 Front or 2 Front 1 Pace. A popular CM7 example is Silence Suzuka, Maruzensky and Taiki Shuttle, who accelerate from first, second and third respectively. |
| Block | - | When an Uma in front of a faster Uma prevents it from overtaking. |
| Bond | Friendship | A value from 0 to 100 attached to Support Cards and NPCs. Support Cards unlock Friendship Training at 80 Bond, and NPC Bonds matter for Unique Skill and post-Career Events. Bond rises through Training and other Career Events. |
| Bowling Ball | - | When an Uma ahead runs out of HP and slows to minimum speed, blocking the Uma behind it. It looks like a ball falling backward and knocking the Uma behind down, since positions on the chart are relative. |
| Broken | Thanos, Umalator (Uma) | Slang for something extremely strong. |
| Career | Career Run, Run | The main roguelike mode of Umamusume, where Trainee Umas are trained across three years into Veteran Umas. |
| Chain Event | - | The main Events of a Support Card, marked by progress arrows. They appear more often than regular Events. SR Cards have 2 Chain Events and SSR Cards have 3. |
| Champions Meeting | CM, Chanmi | The main 3v3v3 PvP Event, with 2 Rounds and a Finals. Group B advances with one win and Group A with 3 wins. Two Leagues exist: Open League for Umas Rank A+ or under, and Graded League with no restrictions. |
| Chariot | I need smaru to drag me around on a leash | A team of two Front Runners plus a third non-Front Runner. The third Uma uses high Wit to enter Pace Up mode, driven by the Lobby Pace the two Front Runners raise. The high pace stops that Uma from entering Pace Down mode by pushing up too far. |
| Charming | - | A Career Condition that raises Bond gain from Training by 2. |
| Christmas | Kurix | Christmas outfits, for example xBiwa and Kuri Oguri, or EN Ashen Miracle Oguri and Rouge Caroler Biwa. |
| Classic Year | Year 2 | The second Year of a Career. |
| Clocks | - | A resource for retrying failed Career Goal Races, usable up to 3 times per Career. |
| Clubhouse Turn | - | The first corner of a race. |
| Colt | - | A male horse aged 4 or under. In-game shown by a decoration on the Uma's right ear. |
| Concentration | Conc | Skill. Start Reaction Time -60%. |
| Condition | - | Positive or negative effects on aspects of an Uma's Career. Negative Conditions can be removed at the Infirmary. |
| Current Speed | - | The Uma's actual Velocity. |
| Daily Races | Farming Races | A permanent PvE mode with three difficulties, used to get Monies or Support Points. |
| Debuff Skill | - | Skills that negatively affect opponent Umas. Shown in-game with a red background. |
| Debuffer | - | An Uma built mainly to use Debuff Skills. |
| Debut | - | The first Race of an Uma's Career, which must be won before any other Race can be run. |
| Dodging Danger | DD | Skill. Lane Movement +2.5%, Target Lane +0.5. |
| Dominator | Dom | Skill. Enemy Speed -0.25. |
| Dueling | Oikurabe | Two or more runners begin dueling in the final stretch when they are in a close struggle for the lead. Those with higher Guts raise their speed more in that situation. |
| Early-Race | Opening Leg | The first sixth of a Race. Shown as phase=0 in Skill Conditions. |
| End Closers | Oiko, 追込, Oikomichaser | A style where the Uma stays at the very back, then makes either a last-to-first spurt in the Final Leg or a move to the front in the Middle Leg. |
| Energy | - | The main resource spent on actions during a Career. |
| Event | - | Conversations during a Career that depend on the Uma, Scenario or Support. Events can offer choices with different rewards. |
| Exhibition | Rooms, Scrims | A PvP mode for Room Matches against other players on custom Tracks, often used to prepare for upcoming PvP Events. |
| Fantasy | F. | Fantasy outfit naming, for example F.Pasa and FGrass. |
| Far Turn | - | The last corner before the homestretch. |
| Fast Learner | Sharp, Kiremono, FL | A Career Condition that lowers all Skill costs by 10% of their base cost. |
| Festival | - | Festival outfits, for example Akizakura Danzatrice Gold City and Archer of the White Moon Symboli Rudolf. |
| Field of View | FoV, Vision | What an Uma can see during a race. It affects vision-based skills such as All-Seeing Eyes. |
| Filly | - | A female horse aged 4 or under. In-game shown by a decoration on the Uma's left ear. |
| Final Corner Velocity Stacking | C4, Velo Bomb | Stacking skills that activate on the Final Corner to greatly raise Target Speed. Umas spread out there, so it is the easiest place to overtake, especially for Backliners. |
| Foal | - | A newborn horse. |
| Friendship Training | Rainbow Training, Rainbows | Happens when a Support Card's Friendship Gauge is at least 80% full and it appears on its own Stat, with rainbow rings around the Training and the card. It is boosted by that card's Friendship Bonus modifier. |
| Front Runners | 逃げ, Nigerunner | A style where the Uma runs to the front immediately and tries to hold the lead for the whole race. |
| Frontline | - | Usually Front Runners. Can include Pace Chasers depending on context. |
| Furlong | - | 1/8 of a mile, or 200m. |
| Gambling Skills | Gamba Skills | Acceleration Skills with inconsistent Activation Conditions. |
| Gate | - | Where Umas start the Race. |
| Give Up | Door, Glue | Exiting a Career. |
| Glue | - | A negative label for a veteran Uma with poor Stats or Skills. |
| Gold Skill | Rare Skills | An upgraded version of some normal Skills, shown in the Skill List with a gold outline. |
| Grand Concert | GL | The fourth Scenario of Umamusume. |
| Grandparent | Sublegacy | The four Parent Umas of the two Parents. |
| Green Skill | - | Skills that raise Stats by a flat value. Shown in-game with a green background. |
| Ground Condition | - | The state of the ground caused by weather: Firm, Soft, Heavy or Good. |
| Ground Type | - | The material of the Racetrack: Turf or Dirt. |
| Groundwork | GW | Skill. Acceleration +0.2. |
| Halloween | H. | Halloween outfit naming, for example H. Creek and HRice. |
| High Roll | Highroll, Getting Lucky | Getting ideal or close to ideal results in an RNG situation. |
| Hint | - | A discount on the Skill Point cost of Skills. |
| Homestretch | Last Spurt | The last 1/6 of the race. The UI fades and the music ramps up when it starts. Shown as phase=3 in Skill Conditions. |
| Hot Topic | - | A Career Condition that raises Bond from Training with NPCs by 40%. |
| HP | - | How far an Uma can run before being forced to minimum speed. It is set by the Stamina Stat and the Race distance. It also decides where the late-race Spurt starts: if HP is too low at the start of the late-race, the Uma delays the spurt until spurting won't drop HP below zero, excluding the final 60m. |
| Ignited Spirit WIT | Aoharu Wit, AW | Skill. Burning Spirit WIT (Lane Movement +3.5%, FOV +15) and Ignited Spirit WIT (Lane Movement +1.5%, FOV +5). |
| Inspiration | Inspo, Inheritance | A Career Event where Stats, Skills and Aptitudes are gained from Parents and Grandparents. |
| Junior Year | Year 1 | The first Year of a Career. |
| Kachisim | VFalatorUmalator | A fork of Umalator with extra features. |
| Kidnapping | - | When an Uma, usually a Frontliner, gets a late start and is blocked by Backliners, forcing it to run from behind. |
| Lane | - | Sections split across the width of the Track. Lane width depends on the course. |
| Last Spurt | - | The mode an Uma enters at the start of the late-race, raising its Target Speed to Top Speed. |
| Late Race | - | The Final Leg (Phase 2) and Last Spurt (Phase 3) of a race together. |
| Late Surgers | 差し, Sashibetweener | A style where the Uma stays toward the back of the pack, between Pace Chasers and End Closers, until the Final Leg. |
| League of Heroes | LoH | An alternate 3v3 PvP Event with 12 Umas (6 player and 6 NPC), where daily Races earn points toward rankings and a server-wide Leaderboard. |
| Legend Races | - | A recurring PvE Event of Races against two to four preset Umas, used to get Star Shards of those Umas and Limit Break Crystal Shards. |
| Length | - | The length of a horse, 2.5m. |
| Lengths | Bashin, L | A unit for distances between horses in a Race, equal to 2m in-game. In real life a Length is about 2.4m. |
| Let's Pump Some Iron! | PumpIron | Skill. Acceleration +0.4. |
| Long | - | The longest Race length category, for Races of 2500m or more. |
| Makaizo | 魔改造 | Literally "Demon Modification": building Umas for Tracks and Styles they have very low Aptitudes for. The term comes from the manga Plamo-Kyoshiro, where it described plastic models modified beyond recognition. |
| Mare | - | A female horse over 4. In-game shown by a decoration on the Uma's left ear. |
| Matikanefukukitaru | Fuku | The Umamusume Matikanefukukitaru. |
| Medium | - | The third Race length category, for Races from 2000m to 2499m. |
| Mid-Race | Middle Leg | The middle 3/6 of a Race. Shown as phase=1 in Skill Conditions. |
| Migraine | - | A Career Condition that stops Mood from increasing. |
| Mile | - | The second Race length category, for Races from 1600m to 1999m. |
| Mood | - | An Uma's condition, split into four levels. It affects Training gains and Stats during a Race. |
| Moving Past, and Beyond | Kanata | Skill. Acceleration +0.4. |
| Narita Top Road | Topro, NTR | The Umamusume Narita Top Road. |
| Navigation Skill | Lane Movement Skill | Skills that affect an Uma's Lane Movement. Shown in-game by a two-sided arrow in the Skill icon. |
| New Years | NY | New Year outfits, for example NY Opera O and NY Haru. Kitasan Black's New Year outfit is informally called Kitasan White. |
| Night Owl | - | A Career Condition with a random chance to lower Energy and/or Mood. |
| No Stopping Me! | NSM, Non-Stop Girl, NSG | Skill. Acceleration +0.4, Lane Movement +2.5%. |
| No-Zone | Normal Zone | The 200m section before the first Corner, where all Umas are forced into Normal Mode: they cancel overtakes and move toward the inner rail. |
| Normal Mode | - | The mode an Uma is in when there are no Overtake targets or while in the No-Zone. Umas generally line up on the inner lane, which makes Overtaking hard. |
| On Your Left! | OYL | Skill. Acceleration +0.4. |
| Operation Cacao | cacao | Skill. Target Speed +0.35, HP Recovery +1.5%. |
| Original | OG | Refers to the original version of an outfit. If no prefix is given, assume the original is meant, for example Red Maruzensky, Blue Teio, OG Mcqueen and OG Oguri. |
| Outing | Dates | A special form of Recreation unlocked through Pal Cards. |
| Overtake | - | When an Uma passes another Uma. Not the same as Overtake Mode. |
| Overtake Mode | - | The mode an Uma enters when preparing to Overtake another Uma. |
| Pace Chaser | 先行, Senkou, leader | A style where the Uma stays toward the front of the pack, between Front Runners and Late Surgers, until the Final Leg. |
| Pace-Down Mode | PDM | The mode an Uma enters when it is too far ahead for its Style during Position Keep. |
| Pacemaker | - | The Uma that sets the Pace Keeping mechanics of the Lobby. |
| Parent | Legacy | The two main Umas chosen for Inspiration. |
| Phase | - | The current section of the Race. A Race has four phases: early-race, mid-race, Final Leg and Last Spurt. |
| Playtime's Over | PTO | Skill. Target Speed +0.15. |
| Position Keep | PosKeep | The mechanic that enforces certain positions for every Uma based on its Style. Umas under a Velocity Skill ignore it. |
| Practice Perfect | - | A Career Condition that reduces Training failure chance by 2%. |
| Practice Poor | - | A Career Condition that increases Training failure chance by 2%. |
| Professor of Curvature | Prof, Curve, PoC | Skill. Target Speed +0.35. |
| Prudent Positioning | PP | Skill. Lane Movement +3.5%. |
| Rabbit | Sac Front, Sac Runaway, Sacrifice, Slingshot | A Runaway that sets a high Lobby Pace for the Race. Often means a Runaway set up to run out of HP in the late-race, giving other Umas a semi-consistent target to proc No Stopping Me! from. |
| Racecourse | - | The general area where Races take place, for example Tokyo Racecourse. Not the same as Racetrack. |
| Races | - | Competitions between Umas to see who is faster. The main source of Skill Points during a Career. |
| Racetrack | Track | The part of the racecourse where the Race takes place, for example the Tokyo 2500m Track. Not the same as Racecourse. |
| Racing Form/Program | - | Shows the background and description of the horse. In-game it is the menu where an Uma's Stats can be browsed before a Race. |
| Recovery Skill | - | Skills that raise an Uma's HP by a percentage. Shown in-game with a blue background. |
| Recreation | - | A Career mechanic that raises Mood and Energy, with a 33% chance to roll each of three possible options. |
| Red Shift/LP1211-M | Redshift | Skill. Acceleration +0.4. |
| Rest | - | The main way to raise Energy during a Career. |
| Runaway | Great Escape, 大逃げ, Oonige | A subset of Front Runners that position themselves even further ahead than regular Front Runners. Counted as a Front Runner for Skill Conditions. See also the Runaway skill. |
| Rushed | Kakari | A mode an Uma enters when it is behind the ideal position for its Style. It raises HP drain and forces the Uma to change to a Style ahead of its own. Front Runners take extra HP drain. |
| Secret Events | - | Uma-specific Events that trigger when a hidden condition is met, often running specific Races. |
| Section | - | A unit of Track division. Each section is 1/24 of any Track. |
| Senior Year | Year 3 | The final Year of a Career. |
| Shooting for Victory | SFV | Skill. Acceleration +0.4. |
| Skill Points | SP | The currency used to buy Skills during a Career. |
| Skin Outbreak | - | A Career Condition with a chance to lower Mood. |
| Slacker | - | A Career Condition that makes an Uma occasionally not show up to Training. |
| Slow Metabolism | - | A Career Condition that stops Speed from increasing during Training. It can be cured randomly through Training. |
| Solo Ace | Oshi Gaming, Double Dom | A team of 1 Ace. The other two Umas are often built as Debuffers to funnel wins into the Ace. |
| Spark | - | A part of a Veteran Uma that decides what it provides at the start of a Career and in an Inspiration Event. |
| Speed Carryover | - | Starting the late-race with extra Velocity because a Velocity Skill's duration overlaps the Final Leg. |
| Spirit Burst | - | A Unity Cup mechanic unlocked after filling a team member's Spirit Gauge. It gives extra Stats and a Skill matching one of the Uma's A Aptitudes. |
| Spirit Gauge | - | A Unity Cup mechanic unlocked three Turns into a Unity Cup Career. It fills through Unity Training and is completely full at four. |
| Spot Struggle | - | When two or more Front Runners fight for the lead early in the Race. It greatly increases HP consumption. |
| Sprint | Short | The shortest Race length category, for Races under 1600m. |
| Spurt Rate | - | The percentage chance an Uma reaches its highest possible Top Speed in the late-race. |
| Stallion | - | A male horse over 4. In-game shown by a decoration on the Uma's right ear. |
| Start Dash | - | The mode an Uma enters at the start of the Race, accelerating faster until it almost reaches Base Speed. |
| Starting Gate | - | The mobile steel structure horses start races in. |
| Straightaway Spurt | Spurt | Skill. Acceleration +0.2. |
| Style | Strategy | The position an Uma keeps through the early and mid-race: Runaway, Front Runner, Pace Chaser, Late Surger or End Closer. |
| Summer | Swimsuit, S. | Summer outfit naming, for example S. Maruzensky, SMaru and Swimsuit Special Week. |
| Support Card | Supoka/Sapoka, Card, Support | Cards representing Umas that assist a trainee during a Career, giving buffs and Events that can improve the result. |
| Survival Rate | - | The percentage chance an Uma finishes the race without being forced down to minimum speed. Not the same as Spurt Rate. |
| Tail Held High | THH | Skill. Target Speed +0.15. |
| Taking the Lead | TTL, Fortune, Fortune Favors the Fast | Skill. Acceleration +0.4. |
| Target Speed | - | The maximum Velocity an Uma can reach. |
| Team Trials | TT | A permanent PvP mode of 5 Races and 15 total Umas, each Race with a different Distance or Ground type. Score earned in the Races keeps or promotes Class. One of the main renewable sources of Carats. |
| Terrain | - | Fixed features of a Track, such as uphills, downhills, corners and straights. |
| The Duty of Dignity Calls | DDC, TDDC | Skill. Target Speed +0.45. |
| Top Speed | Last Spurt Speed | The highest Target Speed an Uma can reach in the late-race. |
| Tote Board | - | A display showing the results at the end of a race. |
| Track Conditions | - | Variable features of a Track, such as weather, season and Ground Conditions. |
| Trackblazer | Make A New Track!, MANT | The third Scenario of Umamusume. Not the same as the Skill of the same name. |
| Trainee | Umamusume, Unit, Character, Uma | The Career-selectable version of a character. |
| Training | - | The main way to raise Stats during a Career. |
| Training Facilities | - | The five locations where Training is done. They can be leveled by Scenario-dependent methods. |
| Turns | - | A unit of action in a Career. Each Turn is half a month. |
| Uma Stan | Stan | Skill. Target Speed +0.15. |
| Umalator | - | A racing simulator for comparing different Uma builds. |
| Under Pressure | Being overtaken | When an Uma is the Overtake target of another Uma currently in Overtake Mode. |
| Unique Skill | Unique | An Uma's exclusive Skill. A weaker version can be inherited by other Umas. |
| Unity Cup | Aoharu | The second Scenario of Umamusume. Some acronyms use the A from Aoharu, for example Ignited Spirit: WIT is often called AW or Aoharu Wit. |
| URA Finale | URA | The first Scenario of Umamusume. |
| Valentine | Choco, V., V | Valentine outfits, for example Choco Bourbon, V. Eishin, VEishin and VBourbon. |
| Velocity | - | The unit for how fast an Uma moves. |
| Velocity Skill | Speed Skill | Skills that raise an Uma's Target Speed. Shown in-game by an Uma running with an aura under her in the Skill icon. |
| Veteran | - | The Uma given as a reward after a Career, used in various modes and as Legacies. |
| Vision Skill | - | Skills that affect an Uma's FoV. Shown in-game by an Uma with a cone ahead of her in the Skill icon. |
| Wedding | Wed, W. | Wedding outfits, for example Wed Groove, W. Mayano Top Gun and WMaya. |
| White Skill | Normal Skills | The base version of a Skill, shown in the Skill List with a white outline. |
| Wide Swing | Narnia, Being in Narnia | When an Uma takes an outer lane while changing lanes at the final Corner, so it runs farther than an Uma near the inner rail. |
| Win Condition | Wincon | Something that must happen for an Uma to win a Race. Usually proper positioning for Acceleration Skills, such as being in sixth to proc Let's Pump Some Iron!. Also often means proccing Recovery Skills so the Uma doesn't run out of HP. |
| Win/Place/Show | - | The three types of horse-racing wagers, for Top 1, Top 2 and Top 3 respectively. |
