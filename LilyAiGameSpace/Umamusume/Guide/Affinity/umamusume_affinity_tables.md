# Umamusume Affinity Tables

Base affinity (compatibility) between Umamusume characters, from the game's own relationship data.

- **Source:** uma.moe public resource `affinity.json` (game version 1.35.2), built from the game's `succession_relation` tables. Names from uma.moe `character_names.json`.
- **Coverage:** 74 characters, the Global roster at that version. Newer characters are not in the data yet.
- **Not included:** G1 race-win bonuses. Those are added on top of the numbers below.

## How to use these tables

Total affinity for a build:

```
total = pair(main, legacy 1) + pair(main, legacy 2) + pair(legacy 1, legacy 2)
      + trio(main, legacy 1, sub-legacy 1-1) + trio(main, legacy 1, sub-legacy 1-2)
      + trio(main, legacy 2, sub-legacy 2-1) + trio(main, legacy 2, sub-legacy 2-2)
      + race-win bonus (if any)
```

- A **pair** value comes from the Pair Affinity Matrix below. It is the same in both directions.
- A **trio** value is the sum of the relationship groups that contain all three characters. It is the same whichever character you treat as the main one, and never higher than the lowest of the three pair values.
- Only the 100 highest trios are listed here. The full set of 56,980 non-zero trios is in the spreadsheet version and in the LilyAi `game_affinity` tool.
- Tiers (community numbers, not official): triangle 50 or less, circle 51 to 150, double circle 151 or more.
