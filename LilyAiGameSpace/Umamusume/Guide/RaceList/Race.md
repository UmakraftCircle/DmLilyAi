# Umamusume Race List (Career Mode Calendar)

Races are listed in **calendar order** (Early = first half of the month, Late = second half). Within the same period, **higher grade comes first** (G1 > G2 > G3 > OP > Pre-OP).

**Notes**
- **Required Fans**: minimum fans needed to enter. **Fan Reward**: fans gained for a 1st-place finish.
- **Race Condition** = course, distance (category), ground, weather and turn direction. Ground/weather are shown as the default **Firm / Sunny**; adjust if a race shows otherwise in-game.
- Fan values come from the Korean-server data on NamuWiki, so Global values may differ slightly. NamuWiki writes some requirements as "over N"; these are shown here as N.
- JBC races are held at a randomly chosen dirt track (Ooi, Kawasaki, Funabashi or Morioka), so their venue and turn direction are listed as "Varies".
- Race names and course list follow [Racelist.md](Racelist.md) (GameTora). Races that run in both Classic and Senior Year appear in both tables.
