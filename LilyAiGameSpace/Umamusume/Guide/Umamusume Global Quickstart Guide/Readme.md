## What the guide is

A short onboarding path for new players on the Global server of Umamusume: Pretty Derby. It walks a beginner from deciding whether the game suits them, through installing and rerolling, to using GameTora's databases and tools.

## Key facts for an agent

- The game is a racing-themed raising sim with roguelite structure, and it is also a gacha game.
- Platforms: PC (Steam), Android and iOS. Cross-platform play with one account is supported.
- The gacha has two pools: characters and support cards.
- Before each career run the player picks 6 supports: 5 owned, 1 borrowed.
- A character is unlocked for Career mode when obtained. After a Career finishes, the resulting stats and skills are saved as a build, and only saved builds can be used in PvP and other non-career modes. Characters can be trained repeatedly.
- Rerolling (deleting account data from the Start screen settings and redoing the tutorial) is easy. The guide advises rerolling for support cards rather than characters, and mentions a free SSR selector ticket at launch.
- Clubs are the guild content. Joining one has no downside and gives extra rewards.
- The Global server runs years behind the Japanese server, so the Japan-server database can be used to preview upcoming characters, supports and gacha banners.
