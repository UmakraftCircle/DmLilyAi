# LilyAiGroqSupport

Groq-specific notes and the Groq cookbook. Provider code itself lives in `LilyAiCore/Providers/Groq/`.

## Cookbook (reference examples)

Runnable Groq examples, each with its own README and requirements. They are reference material and are not imported by LilyAi.
They read model ids from environment variables instead of hard-coding them; see `MODELS.md` for the variable list.

## Automatic model catalog

`MODEL_CATALOG.md` is generated by the scheduled model scan (`LilyAiLearning/Evaluation/model_scan.py`), so it doesn't exist until the first scan runs.
Once a day (`MODEL_SCAN_INTERVAL_HOURS`) LilyAi lists Groq's models, probes new chat models with three cheap calls (plain reply, arithmetic, tool call),
adds passing ones to the pool as fallbacks, and rewrites the catalog. Speech, guard and embedding models are skipped, `groq/compound*` is never auto-added,
and at most 3 models are probed per scan and 6 auto-added in total. State lives in `data/model_scan.json`; run a scan on demand from Settings in the console.

## Model pool (free tier only)

| Model | Role | Notes |
|-------|------|-------|
| `openai/gpt-oss-20b` | chat | fast, high volume; default |
| `openai/gpt-oss-120b` | reasoning | used for long or analytical prompts |
| `qwen/qwen3.6-27b` | alternate | general fallback |
| `groq/compound-mini` | agent | server-side tools; not used for normal chat fallback |

Verify current ids and limits against your Groq console; the catalogue changes. `GroqProvider.list_models()` returns what your key can see.

## Behaviour implemented

- OpenAI-compatible `/chat/completions`; tool calls follow the OpenAI schema
- 429 handling: honours `retry-after` (short waits), otherwise falls through to the next model
- 5xx and network errors retried with backoff
- `json_mode` (`response_format: json_object`) for fact extraction

## Prompting notes

- System prompt keeps replies short for Discord and tells the model to prefer retrieved evidence over guessing
- Facts are injected only when relevant, never recited
